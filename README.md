# NammaMart Quick Commerce Data Pipeline

**IIT Roorkee – Forward Deployed AI Engineering**

This project develops an ETL/ELT data pipeline for NammaMart Quick Commerce, covering data extraction, data quality validation, business rules, quarantine handling, and incremental data loading.

## Project Files

- `dags/` – Airflow DAGs for ETL and ELT workflows
- `dags/nammamart_etl_chandrika.py` — ETL pipeline
- `dags/nammamart_elt_chandrika.py` — ELT pipeline
- `include/` – Extraction, validation, transformation, and supporting modules
- `assignment/` – Submission report and relevant outputs

## Running the Project

The pipeline is developed using Apache Airflow with Astronomer Astro and Docker. Refer to the main project documentation for the workflow and implementation details.
